# Personal Portfolio

A personal portfolio developed to showcase my projects, technical skills, professional background and continuous growth as a developer.

## Live Demo

**[Visit my portfolio](https://portfolio-vinicius-red.vercel.app/)**

## Overview

This project serves as a central space to present my work, highlight my technical knowledge and share my development journey.

## Features

- Personal introduction and professional background
- Technical skills and technologies
- Featured projects and ongoing work
- Professional timeline
- Downloadable résumé
- GitHub statistics
- Contact section

## Tech Stack

- **Framework:** Next.js
- **Library:** React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Web Technologies:** HTML5, CSS3 and JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ViniciusTeles06/portfolio-vinicius.git
```

Navigate to the project directory:

```bash
cd portfolio-vinicius
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm start
```
